# IDRA Day 10 - Flight Operations Data Analysis

## Assignment
Flight Operations Data Analysis – Day 10

## Organization
India Data Research Academy (IDRA)

## Description
This project analyzes a Flight Operations dataset using Python and Pandas.

The notebook follows a complete data analysis workflow including data loading, inspection, selection, filtering, sorting, grouping, aggregation, and data transformation.

## Analysis Performed

- Dataset loading
- Dataset inspection
- Statistical summary
- Missing value checking
- Duplicate checking
- Data selection
- Data filtering
- Data sorting
- Airline analysis
- Origin and destination analysis
- Travel class analysis
- Weather analysis
- Booking channel analysis
- Flight status analysis
- Data transformation
- Seat utilization calculation
- Estimated revenue calculation
- Meaningful observations

## Python Library Used

- Pandas

## Files

- IDRA_Day10_Flight_Operations_Data_Analysis.ipynb
- Day10_Flight_Operations_Dataset.csv

## Conclusion

The project demonstrates how Python and Pandas can be used to analyze flight operations data and identify useful patterns related to passengers, airlines, routes, delays, weather, and booking channels.
